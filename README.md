## About this site

A single-page portfolio built with plain HTML, CSS and JavaScript. There is no build step and no framework.

Sections: About, Live demos, More projects, Skills, Experience, Education, Leadership and achievements, Contact.

Features:
- Typewriter hero line that cycles through what I build
- Animated gradient hero with a cursor-following glow and a 3D photo tilt
- Scrolling tech-stack ticker
- Dark theme by default, with a light and dark toggle
- Scroll progress bar, active section highlighting and scroll-in animations
- Responsive layout for phones, tablets and desktops
- Respects the reduced-motion setting on the visitor's device

## Tech stack

HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript, Google Fonts (Fraunces and DM Sans).

## Run locally

No installation is needed. Download the repo and open `index.html` in any browser.

```bash
git clone https://github.com/Priya28-04/portfolio.git
cd portfolio
# then open index.html in your browser
```

## Deploy on GitHub Pages

1. Create a public repository named `portfolio`.
2. Upload `index.html` (and this README).
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
4. The site goes live at `https://priya28-04.github.io/portfolio/` within a couple of minutes.
